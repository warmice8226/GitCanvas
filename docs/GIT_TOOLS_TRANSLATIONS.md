# Git Tools 설명 언어

- 명령 드롭박스는 `명령 · 짧은 설명`을 표시합니다. 실제 실행에는 명령 이름만 전달합니다.
- 설명 언어의 기본값은 앱의 활성 언어입니다. Git Tools 안의 `한국어 / English` 선택으로 설명을 즉시 전환할 수 있습니다. 입력한 옵션 값과 조립한 명령문은 유지됩니다.
- **명령 설명**에서 한국어 번역 또는 영문 DESCRIPTION을 읽고, **원문 전체**에서 설치된 Git HTML 설명서의 텍스트를 볼 수 있습니다.
- 옵션 목록의 설명은 선택한 언어를 따릅니다. 옵션 탭의 별도 설명·원문·전체 설명서 패널은 제거했습니다. 원문 전체는 명령어 탭에서 볼 수 있습니다.
- 명령 설명과 원문 탭 오른쪽의 **명령사용**을 누르면 옵션 구성 화면으로 이동합니다. 실제 실행은 기존 미리보기·확인 절차를 따릅니다.
- 하단 바이너리 입출력 경로 필드를 제거했습니다. 자유 입력 옵션 값과 대상 값의 **찾기…**에서 파일·폴더를 선택하여 절대경로 또는 현재 저장소 기준 상대경로를 입력할 수 있습니다. 새 파일 경로도 지정할 수 있으며 선택만으로 파일을 생성하거나 덮어쓰지 않습니다. 다른 드라이브는 절대경로를 사용합니다.
- 명령과 옵션은 설명으로도 검색할 수 있습니다. 옵션 이름과 값은 번역하지 않습니다.

긴 설명은 자동 번역임을 화면에 표시합니다. 자주 쓰는 명령의 짧은 설명은 별도로 작성했습니다. 번역 자료는 실행 파일에 포함되므로 실행 중 번역 서비스에 접속하지 않습니다. 설치된 Git의 설명이 달라 번역과 일치하지 않으면 번역 부재를 알리고 원문을 표시합니다.

## 번역 자료 재생성

1. `GitCanvasTests --export-git-manuals -platform offscreen`으로 현재 Git HTML 설명서를 JSON으로 추출합니다.
2. 빌드용 Python에 CTranslate2, SentencePiece를 준비하고 Argos `en_ko` 1.1 모델을 준비합니다.
3. `python scripts/translate-git-manuals.py git-manual-source.json MODEL_DIRECTORY i18n/git-manuals.ko.json`을 실행합니다.
4. `i18n/git-command-summaries.ko.json`의 직접 작성한 짧은 설명이 앱에서 우선 적용됩니다.

원자료는 [Git 공식 설명서](https://git-scm.com/docs)이며 Git 프로젝트의 설명서 라이선스가 적용됩니다. 자동 번역은 [Argos Translate 모델 목록](https://github.com/argosopentech/argospm-index)에서 배포하는 영어→한국어 모델로 생성했습니다. 모델과 Python 의존성은 앱 배포에 포함하지 않습니다. 번역에는 오역이 있을 수 있으므로 정밀한 옵션 의미는 함께 제공되는 원문을 확인할 수 있습니다.
