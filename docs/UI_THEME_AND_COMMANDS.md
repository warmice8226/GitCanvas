# 테마와 명령 조립 화면

## 창과 테마

Windows 실행 파일과 창·작업표시줄 아이콘은 프로젝트 루트의 `assets/gitcanvas-scroll.ico`를 사용합니다. CMake 빌드 시 실행 파일에 포함되므로 배포 폴더에 ICO를 따로 복사할 필요가 없습니다. 같은 파일을 교체하고 다시 빌드하면 새 아이콘을 반영합니다.

왼쪽 위의 **☀️ / 🌙 GitCanvas** 버튼으로 라이트·다크 모드를 전환합니다. 선택은 저장되어 다음 실행에도 적용됩니다. 열려 있는 기본창·플로팅창, Diff, 히스토리에 함께 적용됩니다. Windows 10의 사용자 정의 제목표시줄도 같은 색으로 갱신합니다.

기본창은 크기 변경을 지원합니다. Windows 10에서는 오른쪽 아래 크기 조절 핸들을 끌 수 있습니다. 제목표시줄의 최대화 버튼과 더블 클릭으로 최대화/복원할 수 있습니다.

## 변경사항과 커밋 기록

- 파일 목록/변경 내용 배치 선택은 제거했습니다. 파일 목록은 왼쪽, Diff는 오른쪽입니다. Diff 내부의 통합/나란히 보기와 줄 선택은 유지합니다.
- 작업 디렉터리와 커밋할 파일은 기본적으로 접혀 있습니다. ▸로 펼치고 ▾로 접습니다. ⤢는 펼친 목록을 크게 보거나 기본 크기로 돌립니다.
- 전체 체크, Stage/Unstage와 커밋 입력 기능은 그대로 사용할 수 있습니다.
- 커밋 기록에서 행을 선택한 뒤 **비교 해제** 오른쪽의 **상세 보기** 버튼으로 상세창을 엽니다. 더블 클릭도 유지합니다.

## Git Tools의 전체 Git 명령·옵션 GUI

1. 왼쪽 **명령어** 탭에서 설치된 Git의 명령을 고릅니다.
2. 왼쪽 **옵션** 탭에서 옵션을 찾아 추가합니다.
3. 오른쪽에서 추가한 옵션의 값을 정합니다. 설명서에 고정 선택지가 있는 옵션은 드롭다운으로 제공합니다. 경로·메시지·사용자 정의 포맷 등은 자유 입력을 유지합니다.
4. 하위 명령, 대상 경로, `--` 구분자도 추가하고 순서를 조절할 수 있습니다. 옵션은 반복해서 추가할 수 있습니다.
5. **명령문에 추가**를 누르면 아래에 `git diff --diff-algorithm=histogram`과 같은 완성된 문장이 표시됩니다.
6. **조회 / 실행 미리보기** → **확인 후 실행**으로 진행합니다. 입력을 바꾸면 기존 조립 결과와 실행 승인은 무효화되므로 다시 추가·미리보기해야 합니다. **닫기**도 유지합니다.

표시된 문장은 확인용입니다. 실행은 셸 문자열이 아닌 개별 인자 배열로 전달하므로 공백·따옴표·줄바꿈을 포함한 입력도 별도 셸 명령으로 실행하지 않습니다. 설치된 설명서가 없거나 선택지를 확정할 수 없는 값은 임의의 제한 목록을 만들지 않습니다. 기존 원격 동기화·위험 작업 검토 정책은 유지됩니다.
