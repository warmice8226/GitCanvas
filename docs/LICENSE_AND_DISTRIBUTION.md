# 라이선스와 배포 원칙

## 프로젝트 라이선스

GitCanvas 자체 코드는 `GPL-3.0-only`로 제공합니다. 누구나 사용, 연구, 수정 및 재배포할 수 있으며 배포할 때는 GPL 조건을 따라야 합니다.

저장소 루트의 `LICENSE`에 GPLv3 전체 원문이 있습니다. `THIRD_PARTY_NOTICES.md`에 외부 구성요소와 아이콘 출처를 기록했습니다. 소스·고지 자동 생성과 공개 전 대응 소스 확보 절차는 [무설치 배포](PORTABLE_DISTRIBUTION.md)를 따릅니다.

## Qt

Qt 오픈소스 버전에는 LGPL 또는 GPL로 제공되는 모듈이 있습니다. 프로젝트를 GPLv3로 공개하면 GPL 호환 Qt 모듈 사용이 단순해집니다. 다만 실제 배포 시 사용하는 각 Qt 모듈과 제3자 구성 요소의 고지 조건을 확인해야 합니다.

## Git CLI

GitCanvas는 Git 코드를 링크하지 않고 설치된 `git` 프로그램을 별도 프로세스로 실행합니다. 배포 파일에는 기본적으로 Git을 포함하지 않습니다.

## 배포 체크리스트

- 프로젝트 소스 코드와 빌드 방법 공개
- GPLv3 전체 원문 포함
- Qt 및 다른 의존성의 라이선스와 고지문 확인
- 배포 파일에 필요한 고지문 포함
- 깨끗한 Windows와 Ubuntu 환경에서 실행 확인
- 배포한 소스와 바이너리 버전이 일치하는지 확인

이 문서는 일반적인 프로젝트 관리 지침이며 법률 자문은 아닙니다. 배포 범위나 의존성이 크게 바뀌면 각 라이선스 원문을 다시 검토해야 합니다.
