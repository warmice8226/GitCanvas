# Git manual translation data

`git-manual-source.en.json` is the exported translation input from Git for Windows
2.55.0.windows.5 HTML manuals. Git contributors retain copyright. The applicable
Git GPL v2 notice is preserved in `Git-for-Windows-LICENSE.txt`.

`../i18n/git-manuals.ko.json` is its Korean machine translation with reviewed
overrides. It is shipped as a separate documentation data file, with the same
Git documentation license, and is not covered by the app's GPL-3.0-only grant.
The generator is `scripts/translate-git-manuals.py`; model provenance is recorded
in the output metadata. Original Git sources: https://github.com/git-for-windows/git/tree/v2.55.0.windows.5

The English input is included for modification without needing the original
developer's installed Git manuals. Runtime only needs the translated JSON.
